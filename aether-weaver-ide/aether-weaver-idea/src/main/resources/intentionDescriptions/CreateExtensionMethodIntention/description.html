Creates the extension method a call names, in an extension class for the receiver's type.

An extension is written where the receiver is not: the call reads amount.asMoney("€") and the declaration is a static method, in another class, whose first parameter carries @Receiver. Writing that by hand from the call site means naming the receiver's type, the parameter list and the holder before anything compiles.

The declaration is generated from the call itself — the receiver's type, the arguments' types, and the name as written — into an existing extension class for that receiver where there is one, and into a new one where there is not.

Offered on an unresolved call whose receiver has a type the framework can extend. A receiver that is a primitive, a type variable or a parameterised type is refused: those are AW1304, AW1310 and AW1311, and generating one would be generating the diagnostic. 

amount.asMoney("EUR")
generates 
public static String asMoney(@Receiver BigDecimal self, String currency) { ... }
