Rewrites an @At target as a JVM descriptor.

A source-form target matches by name: "Ledger.flush()" matches a call on any class whose name ends in Ledger, and keeps doing so until a second one appears in the target method and the weave silently attaches to the wrong call. The descriptor form names one class and one signature and cannot drift.

The owner and the descriptor come from the resolved method, not from the text, and the result is resolved again before being offered: it has to land on the same method. Where the target resolves to several methods the intention is not offered, because choosing one of them is a narrowing decision the author makes rather than a change of spelling. 

target = "Ledger.flush()"
becomes 
target = "desc:com/acme/Ledger.flush()V"
