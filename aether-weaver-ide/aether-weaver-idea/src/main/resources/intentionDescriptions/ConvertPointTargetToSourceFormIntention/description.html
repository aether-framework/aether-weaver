Rewrites a descriptor-form @At target the way it reads in Java.

A descriptor carries resolved types already, so this is a rendering and nothing more — and the result is parsed again and has to read back identically before the intention is offered.

It costs precision for readability: the source form matches an owner by simple name, so the conversion widens what the target can match. It is offered because a target nobody can read is its own hazard, not because the two forms are equivalent. 

target = "desc:com/acme/Ledger.flush()V"
becomes 
target = "com.acme.Ledger.flush():void"
