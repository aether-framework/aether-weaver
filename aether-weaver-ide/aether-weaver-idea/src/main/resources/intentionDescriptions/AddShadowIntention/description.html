Declares the @Shadow that makes an unresolved reference inside a weave resolve.

A weave reaches into its target's own state by declaring the member again and marking it @Shadow: the declaration is a promise that the target already has it, and the weaver rewrites every reference to the target's own member. Writing it by hand means copying a type and a signature out of another file.

Offered only where a target really declares a member of that name — and, for a method, exactly one with a matching parameter count. A @Shadow of something the target does not have is AW1030, so generating one from the reference alone would trade a compiler error the reader understands for a framework error they do not.

Not offered in a static weave at all. Its code never moves into the target, so there is no reference for a shadow to be rewritten into; that is AW1090, and the remedy there is @Accessor or @Invoker.

final is dropped. A shadowed field has no initialiser and a weave may not declare a constructor (AW1081), so a final copy would never be definitely assigned and would not compile. Writing to a target's final field is @Shadow(mutable = true) — a deliberate structural change to the target, always reported as AW1033, and not something an intention chooses on the author's behalf.
