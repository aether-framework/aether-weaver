Rewrites a selector's parameter types from simple names to fully qualified ones.

A simple name in a selector is matched against the target's parameter types by simple name, so it binds correctly today and keeps binding until two types in play share one. The qualified form says which was meant, permanently, and costs nothing but width.

The qualified text is not produced by expanding the file's imports — that would be a second implementation of name resolution, disagreeing with the compiler at exactly the interesting edges and doing so invisibly, because the result still parses. Instead the selector is resolved to the one method it names and that method's own erased parameter types are written. Where the selector names no method, or more than one, the intention is not offered.

The rewritten selector is resolved again before being offered and must land on the same method. A qualification that moved the selector to a different overload would be one working selector quietly replaced by another — accepted by somebody who asked for it and will not re-read it.

A selector that names no parameters at all is left alone. Turning "charge" into "charge(java.math.BigDecimal)" narrows a selector that deliberately named every overload, and narrowing is the author's decision, not a formatting change. 

charge(BigDecimal)
becomes 
charge(java.math.BigDecimal)
