Reports a selector string that cannot bind to a member of the weave's target.

The build reports the same defects, with the same AW10xx codes; this inspection only moves the report forward to where the string is being written.

It stays silent whenever it cannot be certain — when no target resolves, when the selector uses a wildcard, or when the annotation has no enclosing @Weave — because a false underline under correct code is worse than a report that arrives one build later.
